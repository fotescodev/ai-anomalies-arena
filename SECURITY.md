# Security

## This repo

Report tooling bugs (XSS in `index.html`, schema holes, issue-template abuse) as a private GitHub security advisory, or an issue if the bug is already public.

Do not file customer data, tokens, or exploit writeups in issues.

## Evidence packs

The locker is client-side. If you find that a future hosted backend would receive raw files, treat that as a vulnerability until encryption and retention are documented.

## Scope we will not take

Instructions for attacking systems, producing weapons, or harming people. Those get closed.
